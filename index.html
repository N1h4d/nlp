Task 1 — Language Model (LM) and Hidden Markov Model (HMM)

What is a Language Model?

A Language Model assigns a probability to a sequence of words. For example, "I read a book" should be more probable than "I a book read". By the chain rule:

$$P(w_1,w_2,\dots,w_n)=\prod_{t=1}^{n}P(w_t\mid w_1,\dots,w_{t-1})$$

Next Word Prediction: given the previous words, compute the probability of every word in the vocabulary and pick the most likely one. Probability is used because language is uncertain: several words can follow the same context, and the model must measure their relative likelihood. The probabilities are learned from counts in a large text collection (corpus).

N-gram models

An N-gram model does not look at the whole history, only at the last n−1 words (the Markov assumption). All words are observed; there is no hidden state.

ModelContextFormula
UnigramNone\(P(w_t)=\dfrac{C(w_t)}{N}\)
Bigram1 previous word\(P(w_t\mid w_{t-1})=\dfrac{C(w_{t-1},w_t)}{C(w_{t-1})}\)
Trigram2 previous words\(P(w_t\mid w_{t-2},w_{t-1})=\dfrac{C(w_{t-2},w_{t-1},w_t)}{C(w_{t-2},w_{t-1})}\)

What is a Hidden Markov Model (HMM)?

In an HMM the sequence is produced by a chain of hidden states, and we only see the observations each state emits. In a language example, the hidden state is a part of speech (noun, verb) and the observation is the word itself.

N-gram LMHMM
StateThe word itself (visible)Hidden state (not visible)
Key probabilities\(P(w_t\mid w_{t-1})\)\(a_{ij}\) (transition) and \(b_j(w)\) (emission)
Typical useDirect language modellingPOS tagging, speech recognition
Important difference: an HMM is a sequence model, not a language model in the classical sense. It can be used for next-word prediction, but then the probability is computed through the hidden states, not from plain N-gram counts.

HMM components and formulas

  • Hidden States: \(Q=\{N,V\}\) (Noun, Verb)
  • Observations: \(V=\{cat,dog,runs,sleeps\}\)
  • Initial Probability: \(\pi_i=P(q_1=i)\), the probability of starting in state \(i\)
  • Transition Probability: \(a_{ij}=P(q_{t+1}=j\mid q_t=i)\), moving from state \(i\) to state \(j\)
  • Emission Probability: \(b_j(w)=P(o_t=w\mid q_t=j)\), the probability that state \(j\) emits word \(w\)

Each row must sum to 1: \(\sum_i\pi_i=1,\ \sum_j a_{ij}=1,\ \sum_w b_j(w)=1\).

Forward Algorithm

It computes the probability of an observation sequence without enumerating every hidden path, using dynamic programming. \(\alpha_t(j)\) is the joint probability of the first \(t\) observed words and being in state \(j\) at time \(t\).

$$\alpha_1(j)=\pi_j\,b_j(o_1)\qquad \alpha_{t+1}(j)=\Big[\sum_{i}\alpha_t(i)\,a_{ij}\Big]\,b_j(o_{t+1})\qquad P(O)=\sum_j\alpha_T(j)$$

How is an HMM adapted for next-word prediction?

After seeing \(o_1\dots o_t\), we first find the distribution of the next hidden state, then combine it with each state's emission probabilities to get the word probability:

$$P(q_{t+1}=j\mid O)=\frac{\sum_i\alpha_t(i)\,a_{ij}}{\sum_i\alpha_t(i)}\qquad P(o_{t+1}=w\mid O)=\sum_j P(q_{t+1}=j\mid O)\,b_j(w)$$

This satisfies \(\sum_w P(o_{t+1}=w\mid O)=1\), so it is a proper probability distribution.

Summary and key points

  • A Language Model assigns probabilities to word sequences and predicts the next word.
  • N-gram counts words directly; an HMM works with hidden states and emission probabilities.
  • The Forward Algorithm computes \(\alpha_t(j)\) recursively; for the next word, transition and emission are combined.

Quick model comparison

These models are not the same kind: N-gram and HMM are statistical, while RNN, LSTM and Transformer are neural-network approaches.

ModelApproachContextKey trait
N-gramStatistical (counts)Last n−1 wordsSimple and fast; cannot see long dependencies
HMMStatistical (hidden states)Previous hidden stateSequence labelling; not a direct language model
RNNNeuralHidden memory vectorReads step by step; vanishing gradient problem
LSTMNeural (RNN variant)Gated memoryKeeps long dependencies better
TransformerNeural (attention)Whole context in parallelFoundation of modern large language models

Summary and key points

  • A language model is a sequential pipeline from data collection to evaluation.
  • Probability calculation (training) and prediction are the core of the model.
  • Model quality is measured with metrics such as perplexity.

How does the chatbot work?

  1. Text Normalization: lowercase, simplify Azerbaijani letters (ə→e), remove punctuation.
  2. Tokenization: split the text into words.
  3. Stopword removal: drop words with little meaning, such as "what", "is".
  4. Keyword Matching: match the remaining words against each topic's weighted keywords (prefix matching handles word endings).
  5. Intent Recognition: pick the topic with the highest score; below the threshold, a fallback answer is given.

Summary and key points

  • Even a simple chatbot needs normalization, tokenization and intent recognition.
  • A rule-based system only recognizes predefined topics and has no general language understanding.
  • Large language models generate answers themselves based on probabilities.
